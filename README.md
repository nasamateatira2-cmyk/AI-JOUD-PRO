# بوت تلجرام مجاني بالكامل (نص + صور)

بوت محادثة عام يستخدم:
- **Groq** (نموذج GPT-OSS 120B) للرد على الرسائل النصية — مجاني بالكامل
- **Pollinations.ai** لتوليد الصور من وصف نصي — مجاني بالكامل، بدون مفتاح

يشتغل كـ **Web Service** على Render (وضع Webhook) لأن خطة الـ Background Worker المجانية اتشالت.

## التشغيل محلياً (اختياري للتجربة)

```bash
pip install -r requirements.txt
export TELEGRAM_TOKEN="التوكن يلي أخذته من BotFather"
export GROQ_API_KEY="مفتاح Groq"
python main.py
```
محلياً رح يشتغل بوضع Polling تلقائياً (لأنه ما في متغير RENDER_EXTERNAL_URL).

## النشر على Render

1. ارفع هاد المجلد على مستودع GitHub جديد.
2. من لوحة Render، اختار **New +** ثم **Blueprint**، واربطه بمستودع GitHub.
3. Render رح يقرأ ملف `render.yaml` تلقائياً وينشئ خدمة من نوع **Web Service** (خطة مجانية).
4. بصفحة الخدمة، روح على **Environment** وأضف:
   - `TELEGRAM_TOKEN`
   - `GROQ_API_KEY`
5. اضغط **Deploy** وانتظر يخلص البناء.
6. افتح البوت بتلجرام وابعتله `/start`.

## الأوامر

- `/start` — بداية محادثة جديدة
- `/reset` — مسح الذاكرة والبدء من جديد
- `/image وصف الصورة` — توليد صورة، مثلاً: `/image قطة تلبس نظارة شمس`

## حدود الاستخدام المجاني

- Groq (GPT-OSS 120B): حوالي **1000 طلب باليوم** و30 طلب بالدقيقة
- Pollinations.ai خدمة مجانية عامة، الجودة والسرعة ممكن تتفاوت أحياناً

## ملاحظات

- الذاكرة محفوظة بالـ RAM فقط، إذا انعاد تشغيل البوت (deploy جديد أو إعادة تشغيل) بتنمسح.
- خطة Render المجانية بتوقف الخدمة (Spin down) بعد 15 دقيقة من عدم النشاط. أول رسالة توصل بعد فترة سكون بياخد ثواني إضافية (Cold Start) لحتى يصحى البوت، وبعدها بيرد عادي.
- إذا بدك تتجنب فترة السكون هاي، تقدر تستخدم خدمة مجانية زي UptimeRobot تبعتلك ping كل شوي على رابط البوت.
